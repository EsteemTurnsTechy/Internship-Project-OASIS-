 Airbnb NYC Data Analysis

 Project Overview
This project explores Airbnb’s New York City dataset to uncover insights about pricing, host activity, property types, and customer preferences.
The goal is to understand market trends that influence host performance and guest satisfaction.

---

 Objectives
- Examine how prices vary across neighborhoods and room types.  
- Identify which neighborhoods are most popular among hosts and guests.  
- Explore the relationship between price, availability, and customer reviews.  
- Present findings through visualizations that reveal actionable business insights.

---

  Dataset
File: `AB_NYC_2019.csv`  
Source: Airbnb Open Data  

Key Columns:
- `name`: Listing name  
- `host_id`: Unique identifier for each host  
- `neighbourhood_group`: Borough of New York (Manhattan, Brooklyn, etc.)  
- `room_type`: Type of property (Entire home, Private room, etc.)  
- `price`: Price per night (USD)  
- `minimum_nights`: Minimum nights required to book  
- `number_of_reviews`: Total reviews per listing  
- `availability_365`: Number of available days in a year  

---

Tools & Libraries
- Python (Data cleaning & analysis)  
- Pandas (Data manipulation)  
- Matplotlib / Seaborn (Visualization)  
- Jupyter Notebook (Interactive analysis environment)

---

 Insights
- Manhattan and Brooklyn dominate the listings and have the highest average prices.  
- Entire homes/apartments are significantly more expensive than private or shared rooms.  
- High review counts do **not necessarily correlate with higher prices.  
- Some hosts manage **multiple listings**, suggesting professional hosting activity.
